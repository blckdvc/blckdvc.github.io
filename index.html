RafaleBatch installer for macOS

Drop a folder of installers, type your password once, walk away.

Rafale reads every .dmg, .pkg and .zip you give it, tells you what each one would do to your Mac, then installs the whole batch in a row.

  • One password for the whole batch, however many packages are queued
  • You see before you install: version, signature, notarization, what is already there
  • Unsigned software is never installed silently
  • Read the scripts a package would run as root
  • Post-install scripts ride along: a .sh or .py next to an installer runs after it as root, with your arguments, output shown live

FouineInstant file search for macOS

Three letters in, every match on every disk.

Fouine keeps an index of all your volumes, so a file name search answers while you are still typing: about 96,000 matches out of 6.3 million items in a fifth of a second.

  • Always current: the index follows every change live, and catches up after a relaunch
  • Hidden files, system folders and external drives included
  • Wildcards and regular expressions, plus filters by kind, date and size
  • Every result, not the first few thousand

LaunchWardenStartup items and processes for macOS

See and control everything that starts with your Mac.

Not just what System Settings chooses to show you: launch agents, daemons, login items embedded in apps, and the background task database, in one list.

  • Real state: running, loaded, disabled or orphaned, read live from launchd
  • Real target and signature behind each item
  • Removal goes to a quarantine, restorable in one click
  • Processes view with the launchd job that started each one

AudioLookAudio loop player for macOS

Hear a loop at your tempo before it reaches your DAW.

A floating player that follows your Finder selection. Pick a sample, loop a region, match the tempo, transpose it, then drag the result into your session.

  • High-quality time-stretch and transposition, on the Signalsmith Stretch engine
  • A/B loop with a click-free crossfade, snapped to the grid if you like
  • MIDI files too, shown as a piano-roll
  • Drag to a DAW: the region, rendered as you hear it

KDownloaderDownload manager for macOS, Windows and Linux

Copy a link. That's it.

KDownloader watches your clipboard. One small app does what usually takes three: a BitTorrent client, a download manager and a debrid front-end.

  • Torrents at Transmission weight, on the librqbit engine
  • Direct downloads through debrid services or straight from free hosts
  • Hands-free: links checked, grouped into packages, resumed, archives extracted
  • About 10 MB, with Tauri rather than a bundled browser

Report WorkshopRemediation reports from Tenable data

From a vulnerability export to a report a client can act on.

A local application that reads a Tenable CSV export, or queries the API, and groups thousands of findings into a short list of concrete remediation actions.

  • PDF and Excel reports, branded per client
  • Plugin names become actions through an editable rule set
  • End-of-life software listed with the machines that run it
  • The data stays on your computer
